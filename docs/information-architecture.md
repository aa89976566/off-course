---

## 2. Strategic rules

1. Projects live inside primary worlds.
2. Archive is a cross-world index only — cases open on world routes.
3. Bridge = metadata, never navigation.
4. Independence is valid; do not force bridges.
5. Homepage: radio discovery + editorial — not a card explanation block.
